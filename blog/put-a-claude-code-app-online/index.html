How to put an app you built with Claude Code online

October 20, 2026 · spawnpoint

Install spawnpoint once, sign in once in your browser, and tell Claude Code "deploy this". A minute or two later Claude Code gives you a link to your app, and the app stays online after you close your laptop. The link is private: it opens only for you, or for your team, until you share it further.

The install is one line in your terminal:

curl -fsSL https://getspawnpoint.com/install | bash

It finds the coding agents on your computer, Claude Code among them, and connects each one to spawnpoint. The first time an agent uses spawnpoint, a browser window asks you to sign in. There are no keys to copy and no settings to fill in.

After that, ask in your own words: "Make a page where my running club says who is coming on Saturday, and put it online." Claude Code writes the app, sends it to spawnpoint, waits until it is running, and replies with the link. If the app fails to start, Claude Code reads what went wrong, fixes the code, and tries again before it answers you.

Change the app the same way: "Add a field for who is bringing snacks, and deploy it again." The link stays the same, so everyone who has it sees the new version. If the new version fails to start, the old one keeps running.

A single page works, and so does an app that keeps data, like a lunch order form, an inventory tracker, or a photo gallery. When an app needs a database or a place to keep files, Claude Code adds one when it puts the app online. Apps made with common web frameworks such as Next.js work as they are.

To let someone else in, ask: "Share it with dana@example.com." Dana gets an email, opens the link, and types a one-time code sent to their inbox. They never make an account. You can also share an app with everyone at your company's email domain, or make it public for anyone with the link.

The same steps work in Codex, Cursor, Copilot, and other coding agents, because the install line sets up each one. The supported agents page has the one step for each, including a Claude chat on claude.ai or in the desktop app.

The free plan keeps one app online at a time, with no time limit and no card. When you sign in, you choose whether your agent deploys for you alone or for your team. A team app belongs to the team, and every member can open it from the team page.
