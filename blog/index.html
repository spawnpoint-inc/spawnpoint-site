  • How to put an app you built with Claude Code online

    Install spawnpoint once, sign in once, and tell Claude Code to deploy. A minute or two later it gives you a private link that stays online after you close your laptop. The same works in Codex, Cursor, Copilot, and a Claude chat.

  • How to share an app with a few people without making them sign up

    On spawnpoint, share the app with their email address. They open the link and type a one-time code from their inbox. Nobody makes an account, and nobody you did not share with can open the app.

  • How to share Claude Code skills and MCP servers with your whole team

    Publish your skills and deploy your MCP servers to a spawnpoint team. Every member's agent sees the team's skills, and one install line adds the team's MCP servers and skills to each person's Claude Code or Codex.
