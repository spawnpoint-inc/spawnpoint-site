Common questions

What is spawnpoint?

The place where your team's AI lives. When your agent builds a tool, an MCP server, or an app that uses AI, spawnpoint puts it online with a link that is private until you share it, with one person or with everyone at your company. You never set up or manage a server.

Do I need to know how to deploy?

No. You sign in once in the browser and your agent takes it from there. spawnpoint runs your app and gives it a secure (HTTPS) web address.

What can my agent build?

Any small web app: a page or a site, an app that keeps data (a to-do app, a lunch order form, a photo gallery), an app that uses AI, or an MCP server your team's agents share. Your agent picks what the app needs, including a database or file storage, and spawnpoint provides it. Apps made with frameworks such as Next.js, Remix, Astro, and SvelteKit work too: spawnpoint runs the build and start scripts in the app's package.json. An app with a Dockerfile is built into a container on its machine, so compiled languages work too.

Can my team run an MCP server on it?

Yes. An MCP server is a small program that agents can ask for things. Your agent builds one, spawnpoint puts it online, and anyone whose agent you give the link to can use it. If you keep it private, each person's agent signs in once with an email you shared it with.

Can my app use AI without an API key?

Yes. spawnpoint runs open-source AI models itself. When an app needs AI, your agent asks whether to use them, and if you say yes, the app works with no OpenAI or Anthropic account and no key to paste in. The blog post You can spawn AI apps now shows what they can do.

How does my agent connect?

One command sets up whichever coding agents are on your machine. It works with Claude Code, Codex, Cursor, Copilot, and many more:

$curl -fsSL https://getspawnpoint.com/install | bash

Then sign in once in the browser for each agent. The supported agents page has the exact step for each. Any other MCP client needs only https://app.getspawnpoint.com/mcp.

Who can see what I deploy?

Only you, until you say otherwise. New projects are private by default: share them with specific people by email, or with everyone at your company through a domain like @acme.com (they verify with a one-time code, no account needed), or make them public for anyone with the link. Your agent can do both, and so can the console.

Is it safe to deploy code my agent wrote?

spawnpoint refuses an app with a recognizable API key (AWS, Stripe, OpenAI, Anthropic, GitHub, and others) written into its code, and the plugin's security audit checks an app before it ships: leaked keys, files that should not upload, debug mode, and admin pages with no login. Every project runs on its own isolated machine.

How much does it cost?

Free covers one live project at a time. Pro is $50 a month for unlimited projects, and up to 3 of them never sleep, so their visitors never wait for them to start. It is a flat monthly subscription with nothing to top up, and you manage or cancel it in the console.

Can I use my own domain?

Yes. Ask your agent to add your domain: it gives you the DNS records to create, and HTTPS is set up automatically once spawnpoint confirms them. The spawnpoint link keeps working too.

What happens when nobody is using my app?

It sleeps: the machine stops while it is idle, and the next visit wakes it in about half a minute. Redeploying also wakes it. On Pro, up to 3 apps can stay always on instead, so nobody waits.

Can I take a project down?

Yes. Open the project in your console and click Terminate, or ask your agent. The app is permanently shut down, and billing stops immediately.
