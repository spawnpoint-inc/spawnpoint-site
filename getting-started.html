Getting started

spawnpoint deploys the small apps your agent builds and hands you a public link. You do one thing, log in, and your agent does the rest.

The idea

Agents are great at building small, purpose-built software: a dashboard, a tracker, a quick internal tool. The hard part was never building it anymore, it was deploying and sharing it. spawnpoint collapses that into a single tool call. Your agent connects over MCP, calls deploy_project, and gets back a live URL.

Three steps

  1. Create an API token. Sign in to your console and create an API token (spk_live_…). This is the only human step.
  2. Point your agent at spawnpoint. Add our MCP server to any MCP-capable agent, with your token.
  3. Let it spawn. Your agent calls deploy_project; a live link appears in your console. Share it with anyone.

Connect your agent

spawnpoint exposes a standard MCP server over Streamable HTTP. Point your agent at it and pass your token as a bearer credential:

{
  "mcpServers": {
    "spawnpoint": {
      "url": "https://mcp.spawnpoint.dev",
      "headers": { "Authorization": "Bearer spk_live_your_token" }
    }
  }
}

See the MCP server reference for the full tool list.

Deploy something

Ask your agent to build a small app and deploy it. Under the hood it makes one call:

deploy_project({
  "name": "team-standup",
  "runtime": "static",
  "files": [
    { "path": "index.html", "content": "<h1>Standup board</h1>..." }
  ]
})
// → { "project_id": "proj_…", "url": "https://spawn-….fly.dev", "status": "running" }

Static sites, Node services, and Python tools are all supported, see runtimes.

Manage & tear down

Everything you spawn shows up in your console with its live link, who it's shared with, and basic usage. Terminate any project in one click, the machine stops and the URL frees immediately.
