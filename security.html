Security

How spawnpoint protects your account, your tokens, and the code you deploy.

Accounts & tokens

  • Passwordless login. You sign in with a link sent to your email, so there is no password to leak.
  • Tokens stored as hashes. We store only a hash of each API token. You see the full token once, when you create it, and we cannot recover it.
  • Revoke anytime. Revoke a token or terminate a project from the console and it stops working immediately.

Isolation

Each project you deploy runs in its own virtual machine, which we manage. Projects do not share a machine, so one project cannot reach into another.

Teardown

Terminate is one click. The machine is destroyed and the URL is freed right away, so nothing keeps running or adds to your bill.

Your data

We store only what is needed to run your projects: your account email, project metadata (name, status, URL), and the code bundles you deploy.

Reporting an issue

To report a security issue, email founders@getspawnpoint.com. We will respond quickly.

Pre-launch note. spawnpoint is in public beta and has not yet had a third-party audit. We are improving security as we go, and we will keep this page up to date.
